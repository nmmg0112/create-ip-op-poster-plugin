# 项目级完整 Prompt 基准（公开通用版）

## 用途

本案例完全虚构，只用于检查 Prompt 的完整度、映射准确性和可执行性，不对应任何真实客户、项目、达人或账号。

成功基准包括：明确画幅与用途、逐组玩法、成员映射、案例截图映射、相对构图、视觉语言、素材角色、固定信息、验收条件和负面要求。人物素材必须在使用本基准前完成并获得 `人物素材通过`；本例不增加独立排布确认。

## 不得固化

不得把本示例的主题、分组数量、版式、配色或“人物第一视觉”变成其他项目的默认规则。真实项目必须根据当前 Brief、人物内容特征、素材关系和用户确认重新判断。

## 虚构示例

```text
请设计一张 16:9 横版内容创作者矩阵招商 OP，高清商业提案质感，信息清楚、视觉优先。

【任务边界】
人物素材已经完成白底组合预览、同排布透明总图和独立透明抠图确认。最终使用方式取决于已选择的模式：模式 A 把全部素材作为可能被重绘的生成参考；模式 B 先生成艺术位图底图，再覆回原始保护图层。不得混写两种保真承诺。

【主题】
项目主题：城市灵感接力（虚构）
主题文案：让每一种内容能力，都有清楚的出场位置
项目背景：用三类互补内容机制呈现创作者矩阵的合作价值。

【版式结构层】
画布：16:9 横版，四周保留安全边距。
区域比例：顶部主题区约 18%；中部三组玩法区约 68%；底部合作信息约 14%。
阅读顺序：主题 → 三组玩法与人物 → 案例证据 → 合作信息。
信息密度：中高；使用编号、稳定对齐和颜色编码，不把必要文字压成小字。
主要留白：只用于聚焦标题、分隔模块和引导阅读，不留无意义空白。

【玩法内容】
1. 场景体验组
成员：创作者 A、创作者 B
一句玩法：让产品进入真实生活任务，通过具体行动证明使用价值。
案例截图：C01、C02，完整并排放置。

2. 挑战验证组
成员：创作者 C、创作者 D
一句玩法：用明确条件和完成结果验证产品能力，突出真实反应。
案例截图：C03、C04，完整并排放置。

3. 创意表达组
成员：创作者 E、创作者 F
一句玩法：围绕同一命题完成差异化作品，让最终内容成为视觉证据。
案例截图：C05、C06，完整并排放置。

【人物与玩法关系】
逐条写明 P 编号、公开昵称、所属玩法、相对大小、前中后景角色、交叠关系和脸部／动物头部安全区。描述可供生图模型理解的关系，不用大量精确坐标锁死艺术构图。不得新增、遗漏或重复人物与动物。

【案例截图】
六张截图分别映射到 C01—C06。模式 A 明确披露截图可能被重绘或写错；模式 B 使用完整原图层，只可等比缩放和摆放，不得裁切、改字、改数据、调色、重绘、修复或虚构。

【Logo】
逐条写明 L 编号、角色和相对大小。模式 A 明确披露 Logo 可能被重绘；模式 B 保留所有原始元素，只可去除背景、等比缩放和排列。

【艺术指导层】
颜色、材质、容器和装饰必须来自当前 Brief、人物／账号证据、品牌规则、受众情绪或内容机制。不得根据行业标签自动套用固定风格。
明确第一视觉、第二层玩法、第三层证据，以及前景、中景和背景。
装饰必须服务当前视觉母题，并规定数量或使用范围。

【素材角色表】
P：逐条列出人物／动物编号、来源与玩法角色。
C：逐条列出案例截图编号、所属玩法与来源。
L：逐条列出 Logo 编号与来源。
T：逐条列出固定文案原文与视觉角色。

【固定信息】
只写用户明确提供并确认的合作方式、报价、权益或收束文案；未提供的信息不得出现。

【参考边界】
参考案例只用于学习阅读路径、信息密度和视觉气质。不得复制标题、文案、Logo、印章、专属容器、具体人物排布或标志性装饰。

【美观预检】
第一视觉明确；人物与玩法关系清楚；大小节奏成立；主要留白有用途；前中后景完整；装饰与母题相关；高密度信息仍可快速扫描。

【输出与验收】
人物／动物数量、截图数量、Logo 数量和固定文案与素材台账一致。中文清晰，无乱码；保持安全边距；文字不压脸；截图不裁切；不得添加虚构数据、客户名称、合作案例、报价或权益。

【负面要求】
不要新增、遗漏或重复人物／动物；不要密集小字；不要留下无意义空白；不要做 PPT 式等权卡片墙；不要照抄参考；不要添加未确认的业务内容。模式 A 不得声称像素保真；模式 B 不得重画人物、动物、截图或 Logo。
```

## 新版双模式使用方法

这份虚构示例只证明“完整 Prompt 应该包含什么”，不会替当前 Brief 预选季节、版式或人物主次。最终 Prompt 展示轮是纯文字确认，以 `确认生成` 收尾，不消耗正式海报生图次数。

### 模式 A：快速生图

把共享 Prompt、已确认人物素材、案例截图和 Logo 一并交给生图模型，由模型一次完成整张海报。逐项列出允许生成式重绘的 `P/C/L/T`，并向用户说明人物、截图、Logo 和中文可能变化，不能声称原样保留。默认只调用一次正式生图。

### 模式 B：保真合成

第一项生产动作必须调用生图模型，先生成一张完整的 PNG、WebP 或 JPEG 艺术底图。底图包含主题场景、构图、材质、光影、前中后景、装饰语言和视觉动势，并为 `P/C/L/T` 保护图层留下自然角色；不得生成或仿制其受保护内容。

不得使用 SVG、HTML、Canvas、PPT、Sharp、固定矩形、规则色块或头像网格创建、替代或栅格化底图。真实位图落盘后，才可把透明人物总图或独立透明抠图、完整案例截图、原 Logo 和准确中文作为保护图层覆回，并验证非目标区域未改变。

## 质量判断

如果真实项目的最终 Prompt 没有做到逐人物、逐截图、逐玩法和逐素材角色映射，就不能因为篇幅短而称为“更精炼”。如果它复用了示例的行业、配色或版式，也不能称为“已根据 Brief 定制”。模式 B 若没有可追溯的生图位图底图，或把程序化页面当底图，必须判定失败。
