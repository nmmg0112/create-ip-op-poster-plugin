# IP/OP 海报制作 Plugin

把 IP 征集 Brief、达人／人物／动物原图、案例截图和 Logo，整理成可确认、可执行、可验收的中文招商海报工作流。

## 最简单的用法

安装后上传 Brief 和人物原图，然后发送：

```text
@create-ip-op-poster 我有 Brief 和人物原图。请从第 1/4 步开始，先给我 2—3 个创意方向，不要直接成图。
```

在 Codex 中把 `@create-ip-op-poster` 改为 `$create-ip-op-poster`。

## 四次确认

1. `选方向 1`
2. `抠图通过`
3. `排布通过`
4. `确认生成`

Plugin 不会跳过确认，也不会把人物、动物、案例截图或 Logo 交给模型重新绘制。平台无法保真处理时，会给出可交接的抠图说明、图层表、完整 Prompt 和 QA 清单。

## 功能范围

- 任意行业、季节和营销节点的 Brief 解析；
- 单达人玩法或多人矩阵分类；
- 视觉案例检索、信息密度和版式选择；
- 新手模式和一次一个问题；
- 人物／动物抠图确认与人物排布确认；
- 项目级完整成图 Prompt；
- 人脸、动物、截图和 Logo 保护；
- 最终 QA 和跨平台交接。

版本 `0.1.2` 是纯 Skill Plugin，不包含 MCP 服务，不登录第三方系统，也不会独立收集或上传文件。

## 临时上传压缩包

没有安装入口时，可以把发行压缩包上传到当前对话，并明确要求 AI 读取其中的 `SKILL.md` 后执行。临时上传只在当前对话中生效；安装 Plugin 的触发和资源读取更稳定。

## 公开案例边界

公开包不分发版权状态不明确的行业海报原图，也不公开内部案例来源或文件名。它提供抽象视觉语法和六张原创匿名版式示意图。需要参考具体海报风格时，请在当前任务中上传你有权使用的参考图。
