# IP/OP 海报制作 Plugin

把获授权的人物／动物原图、IP 征集 Brief、案例截图和 Logo，整理成有具体内容玩法、可直接查看的中文招商海报。版本 `0.4.0` 增加自动新手开场、Aime Image2／豆包 Seedream 5.0 Pro 适配、锁定需求和成功版本保护。

## 最简单的用法

安装或上传完整 Skill 包后，只发送：

```text
@create-ip-op-poster 请告诉我怎么使用，并带我开始制作一张 IP／OP 招商海报。
```

在 Codex 中可将 `@create-ip-op-poster` 改为 `$create-ip-op-poster`。Skill 会自动解释人物与案例的作用并给出极简填写提示，不要求用户复制长 Prompt。Brief、案例、Logo 和固定文案可以一起上传，也可以在人物确认后补充。

Aime 使用 Image2；豆包的人物素材处理和正式海报使用 Seedream 5.0 Pro。两者都先把当前需求整理为 `LockedPosterSpec`，不把零散聊天直接交给生图模型。用户通过第一版后建立 `PosterVersionLock`，准确文字、Logo 和案例修改不得整图重绘。

## 你只需要确认两次

1. Plugin 只展示一张横版白底人物组合预览。没有说风格时，它会在这条消息里顺带问一句；不回答也不影响继续。确认没有错脸、漏人、重复或明显残边后，回复：

   ```text
   人物没问题
   ```

2. Plugin 读取 Brief 和案例，先把每组达人“谁在什么场景做什么、产品如何进入”写清楚，再给一个推荐方案和一个真正不同的备选方案。选择后回复：

   ```text
   选 1 生成
   ```

这句话同时完成方案确认和正式生图授权，不再增加排布稿、技术路线或长 Prompt 确认。

## 视觉偏好可以跳过

如果你已经说了“浅蓝清爽”“暖色活力”“不要太科技”等偏好，Plugin 不会重复问。没有想法也没关系，它会结合 Brief、达人案例和视觉参考推荐配色、材质、光影与整体气质。视觉偏好不是第三个确认点。

## 默认生成规则

- **默认整图生成**：一次生成包含主题、人物、具体玩法、案例和商务信息的完整海报；
- OP／招商主海报固定使用 **16:9 横版**；只有明确的竖版渠道或适配用途才改比例；
- 不先生成空背景、空舞台、排布稿或程序化信息板；
- 默认只正式生图一次，不用重复图片消耗次数；
- 最终必须实际查看成图，竖版、无玩法、PPT 感、空背景、人物与玩法脱节、错脸、漏人、重复、乱码或无法预览都不能宣布完成。

默认整图会尽量保持人物和案例，但可能产生细节变化，不承诺逐像素不变。

## 素材必须完全不变时

如果你明确要求人脸、案例文字、Logo、数据或固定中文完全不变，Plugin 会在后台自动切换为**严格保真**制作，不会让你选择技术方式。它会优先锁住原素材，让生图模型围绕真实人物和案例生成完整艺术环境，再覆回原图层校验，减少“背景很美、人物像贴上去”的问题。当前平台做不到时，它会交付已经确认的方案、完整执行内容和素材映射，不会拿低质量成品代替。

成图后只添加 Logo、修改准确中文、报价、权益、案例或一个元素时，只做局部图层修改，**不得整图重绘**；其他区域必须保持不变。

## 功能范围

- 人物素材确认与身份、数量、边缘检查；
- Brief 解析、单达人玩法和多人矩阵分组；
- 可选视觉偏好与 Brief 的联合转译；
- 结构、密度和气质参考，以及不照抄的视觉导演；
- 具体玩法预检、默认整图生成和后台严格保真；
- 局部精确修改、实际成图 QA 和跨平台交接。

这是纯 Skill Plugin，不包含 MCP 服务，不登录第三方系统，也不会独立收集或上传文件。实际生图与分层能力取决于当前宿主。

## 临时上传压缩包

没有安装入口时，可以把发行压缩包上传到当前对话，并要求 AI 读取其中的 `SKILL.md` 后执行。临时上传只在当前对话中生效；安装 Plugin 后，触发和资源读取更稳定。

## 公开案例边界

公开包不分发版权状态不明确的行业海报原图，也不公开内部案例来源或文件名。它提供抽象视觉语法和原创匿名版式示意图；这些示意图只用于解释关系，不能成为艺术底图、完整海报预览或最终海报。需要参考具体风格时，请上传你有权使用的参考图。
