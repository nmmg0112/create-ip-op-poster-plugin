# IP/OP 海报制作 Plugin

把获授权的人物／动物原图、IP 征集 Brief、案例截图和 Logo，整理成可确认、可生产、可验收的中文招商海报。新版先确认人物素材，再选择快速整图生成或保真合成。

## 最简单的用法

安装后先上传人物／动物原图，然后发送：

```text
@create-ip-op-poster 请先处理这些人物素材并让我确认，不要先给创意方向或生成海报。
```

在 Codex 中把 `@create-ip-op-poster` 改为 `$create-ip-op-poster`。Brief、案例截图、Logo 和固定文案可以现在一起提供，也可以在人物确认后补充。

## 当前流程

1. Plugin 先产出横版白底组合预览、同排布透明人物总图和各主体独立透明抠图，等待 `人物素材通过`。
2. 人物通过后，Plugin 给出 2—3 个创意方向，并让你同时选择：
   - 模式 A｜快速生图：整张海报一次生成，更快、更统一，但人物、截图、Logo 和中文可能被重绘；
   - 模式 B｜保真合成：先生图生成完整艺术位图底图，再覆回确认过的人物、截图、Logo 和准确中文。
3. Plugin 展示完整文字 Prompt；只有收到 `确认生成` 才进入正式制作。默认只正式生图一次，不会因失败自动消耗第二次。

方向与模式可以直接回复：

```text
选方向 1，用模式 B
```

## 模式 B 的硬规则

第一项生产动作必须调用生图模型，生成真实 PNG、WebP 或 JPEG 艺术底图。SVG、HTML、Canvas、PPT、Sharp、固定色块、头像网格或其他程序化页面不能创建、替代或伪装成这张底图。

位图底图落盘后，程序才可做蒙版、等比缩放、保护图层合成、准确中文栅格化、格式转换和验证。若宿主没有生图能力，Plugin 只输出完整 Prompt 与素材映射交接包，不会用程序化信息板冒充最终海报。

## 功能范围

- 人物素材优先与身份／数量／边缘检查；
- 任意行业、季节和营销节点的 Brief 解析；
- 单达人玩法或多人矩阵分类；
- 匿名视觉语法、信息密度和生成式构图选择；
- 模式 A 整图生成与重绘风险披露；
- 模式 B 位图先生图与人物、截图、Logo、固定中文保护；
- 完整成图 Prompt、最终视觉 QA 和跨平台交接。

版本 `0.2.0` 是纯 Skill Plugin，不包含 MCP 服务，不登录第三方系统，也不会独立收集或上传文件。实际生图与分层能力取决于当前宿主；能力不足时会明确停止并交接。

## 临时上传压缩包

没有安装入口时，可以把发行压缩包上传到当前对话，并明确要求 AI 读取其中的 `SKILL.md` 后执行。临时上传只在当前对话中生效；安装 Plugin 的触发和资源读取更稳定。

## 公开案例边界

公开包不分发版权状态不明确的行业海报原图，也不公开内部案例来源或文件名。它提供抽象视觉语法和六张原创匿名版式示意图；这些 SVG 只用于解释关系，绝不能作为模式 B 底图、完整海报预览或最终海报。需要参考具体海报风格时，请在当前任务中上传你有权使用的参考图。
